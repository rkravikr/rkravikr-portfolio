## 10. MOTION DESIGN AND INTERACTIONS

Develop a cohesive motion language rather than adding random animations.

Consider the following:

### Hero animation

A restrained 3D object with realistic reflections, subtle lighting changes and slow rotation.

### Scroll-driven storytelling

Sections reveal themselves through carefully timed transitions, typography masks, image movement and subtle depth changes.

### Text animation

Use staggered reveals, clipping masks and controlled movement for selected headings.

### Image transitions

Use restrained image scaling, masking, light sweeps or displacement transitions where they improve the story.

### Project interactions

Use clear hover feedback, subtle image movement and meaningful transitions into project details.

### Ambient atmosphere

Use limited grain, particles, procedural gradients or shader-based effects where they contribute to the art direction.

### Navigation

Use an elegant navigation system that remains understandable and accessible. Avoid hiding essential navigation behind obscure gestures.

For each proposed animation, explain:

- What triggers it.
- What the visitor sees.
- Its purpose in the narrative.
- Its expected duration or pacing.
- Whether it uses CSS, GSAP, WebGL or another technique.
- How it behaves on mobile.
- What the fallback behavior should be.

Avoid excessive scroll hijacking, forced waiting, motion that interferes with reading, cursor effects that reduce usability, and animations that exist only to demonstrate technical complexity.

Respect reduced-motion preferences.
